## FAQ

**Q: Can I use the AGPLv3 version for my company?**  
A: Yes, if your use complies with AGPLv3 terms. If you distribute the software or its functionality over a network, AGPLv3 requires you to make your source code available. The commercial license removes this requirement.

**Q: Do I need a commercial license to run the proxy internally?**  
A: No. The AGPLv3 covers internal use without additional cost.
